# 🥣 Bowl Lab — Costos que rinden

Calculadora de costos y precios para un negocio de bowls. Pensada para saber, número en mano, cuánto cuesta hacer cada bowl y a qué precio conviene venderlo.

## ¿Qué hace?

- **Carga de ingredientes**: precios, unidades y proveedores.
- **Armado de recetas**: elegí qué ingredientes lleva cada bowl y en qué cantidad.
- **Cálculo de costos**: ingredientes + packaging + costos indirectos (alquiler, servicios, etc.) prorrateados por volumen mensual.
- **Precios sugeridos**: margen mínimo, margen objetivo, markup para venta al consumidor, y comparación contra la competencia.
- **Punto de equilibrio**: cuántos bowls hay que vender por mes/día para cubrir los costos fijos.
- **Registro de ventas**: para ir viendo facturación y ganancia real.
- **Guardado automático**: los datos quedan guardados en el navegador (localStorage), así que no se pierden al cerrar la página.

## Cómo usarlo

Es un único archivo HTML, no necesita instalación ni servidor. Solo hay que abrirlo en el navegador:

1. Descargá el archivo `bowl-lab.html`.
2. Abrilo con doble click (se abre en tu navegador).
3. Empezá cargando tus ingredientes y armando tus recetas.

También podés usar [GitHub Pages](https://pages.github.com/) para tener una versión online sin descargar nada.

## Tecnología

- HTML + CSS + JavaScript puro (vanilla), sin frameworks ni dependencias externas.
- Fuentes de Google Fonts.
- Persistencia de datos vía `localStorage` del navegador.

## Estado
